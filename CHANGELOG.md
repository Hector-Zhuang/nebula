## [0.1.0] - 2026-09-22

First public release. Nebula is an enterprise-grade SuperApp framework built on
React Native: a native host runs independent, pure-JavaScript MiniApps that are
developed, distributed, and rolled back without host app releases.

### Added

#### Framework runtime (`@nebula-rn/sdk`)

- `NebulaAPI` host integration surface: MiniApp installation, opening/closing,
  manifest registration, update checks and preloading
  (`preloadMiniApp` / `preloadMiniAppWithBundleURL`)
- `Miniapp` runtime with native page-stack navigation: `navigateTo`,
  `redirectTo`, `reLaunch`, `navigateBack`, plus query-param injection
- Page lifecycle hooks: `usePageOnLoad`, `usePageOnShow`, `usePageOnReady`,
  `usePageOnHide`, `usePageOnUnload`, and the `createMiniAppPage` wrapper
- `definePageConfig` and per-page navigation/background configuration
- Versioned Host API protocol (`api.v1`) with capability discovery
  (`getCapabilities`), request/response correlation, subscription event
  streams, and a modal API channel
- MiniApp bootstrap/runtime entry generation consumed by the CLI

#### Native host (`@nebula-rn/host`)

- iOS (Swift) host runtime: app/bundle management, container controller,
  router and URL parser, native module bridge, single-slot MiniApp preloading
  with generation-safe cache invalidation, and `NebulaPerformanceMonitor`
- Android (Kotlin) host runtime: equivalent app management, activity
  containers, router, event hub, and a multi-slot ReactHost preload pool
- Host configuration and manifest handling on both platforms

#### Official host APIs (`@nebula-rn/host-apis`)

- System info, app base info, KV storage, file system, network status,
  location, clipboard, screen brightness, phone call, image
  picker/compression/preview, file upload/download, sensors, and
  user-capture-screen observation
- Modal capabilities owned by the host: QR/barcode scanning and image preview
  with host-provided native UI
- MiniApp update APIs (`getMiniAppUpdateInfo`, `applyMiniAppUpdate`)

#### MiniApp client APIs (`@nebula-rn/client`)

- Stable JavaScript API surface for MiniApp developers covering storage,
  media, location, clipboard, file system, network, sensors, scanning,
  preview, and update management

#### UI components (`@nebula-rn/components`)

- Cross-platform components: Camera, Map, Progress, RichText, Slider, Swiper
  (with carousel and pagination), Video, and WebView

#### CLI (`@nebula-rn/cli`)

- `nebula create host|miniapp|runner` project scaffolding with built-in
  templates (`--app-id`, `--display-name`, `--bundle-id`, `--directory`)
- `nebula miniapp dev`: generated runtime entry/Metro config, Dev Runner
  orchestration, and `devrunner://` deep-link launching on iOS and Android
- `nebula miniapp build`: production iOS and Android bundles plus assets and
  runtime manifest
- `nebula miniapp upload`, `nebula auth login/logout`, and
  `nebula config server` for Nebula Cloud integration

#### Developer tooling

- `@nebula-rn/dev-runner`: universal development host for MiniApp development
  without a production host
- Example projects: a SuperApp scenario (one host with payment-code,
  ride-hailing, shopping, and tickets MiniApps), a native iOS host, and a
  coding-agent host demonstrating AI-generated MiniApps with an MCP server
- Trilingual documentation site (English, Chinese, Arabic) covering host,
  MiniApp, Host APIs, CLI, and Nebula Cloud

#### Nebula Cloud (`@nebula-rn/cloud`) and console

- Self-hostable NestJS + Prisma/PostgreSQL service: registration/login with
  JWT, MiniApp creation and membership, version upload, release/experience
  channels, one-click rollback via a current-release version pointer, and
  distribution records
- React management console for MiniApp and version administration,
  deployable via Docker Compose

### Security

- Per-MiniApp file-system and KV-storage sandboxing, independent JS runtime
  contexts and bridges, and cross-MiniApp communication mediated by the host
- MiniApp-level domain settings and sensitive-scope declarations in Nebula
  Cloud
- `SECURITY.md` with private vulnerability reporting and a response SLA

### Notes

- License: Apache-2.0 for the framework, official packages, Cloud, console,
  CLI, and documentation
- npm distribution uses scoped `@nebula-rn/*` package names; the bare `nebula`
  npm name belongs to an unrelated package
- Stricter JavaScript capability sandboxing, host-side API guards,
  percentage-based rollout/A-B testing, Android performance instrumentation,
  crash reporting, delta bundle updates, and a formalized MCP server are
  planned for upcoming releases (see the roadmap in the documentation)
