Nebula 是一套面向超级应用的小程序方案。它提供宿主运行时、小程序执行模型、安装与 bundle 加载链路、预加载能力，以及由宿主拥有的 API 架构，例如 `scanCode` 这类能力。

Nebula 主要面向三类角色：

- 将 Nebula 集成到宿主应用中的平台工程师
- 基于 Nebula 运行时构建业务体验的小程序工程师
- 扩展基础库与宿主能力模型的框架工程师

## Nebula 解决什么问题

- 比随宿主发版更快的业务迭代节奏
- 明确由宿主拥有并治理原生能力
- 为小程序团队提供稳定的 JavaScript API
- 同时支持开发态与生产态运行模式
- 通过预加载和生命周期控制缩短启动时间
- 支持 Modal 与非 Modal 能力的可扩展 Host API 架构
