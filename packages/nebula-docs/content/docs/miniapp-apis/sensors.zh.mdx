---
title: 传感器
description: 使用 Nebula 的传感器订阅 API 获取加速计、陀螺仪、磁力计和气压计数据。
---

Nebula 提供四种设备传感器的数据订阅 API：加速计、陀螺仪、磁力计和气压计。

## 加速计

监听设备加速度变化：

```ts
import { onAccelerometerChange } from '@nebula-rn/client';

const unsubscribe = onAccelerometerChange((data) => {
  console.log(`x: ${data.x}, y: ${data.y}, z: ${data.z}`);
}, 200); // 采样间隔 200ms

// 停止监听
unsubscribe();
```

## 陀螺仪

监听设备旋转角速度：

```ts
import { onGyroscopeChange } from '@nebula-rn/client';

const unsubscribe = onGyroscopeChange((data) => {
  console.log(`x: ${data.x}, y: ${data.y}, z: ${data.z}`);
}, 100);

unsubscribe();
```

## 磁力计

监听设备磁场强度：

```ts
import { onMagnetometerChange } from '@nebula-rn/client';

const unsubscribe = onMagnetometerChange((data) => {
  console.log(`x: ${data.x}, y: ${data.y}, z: ${data.z}`);
}, 100);

unsubscribe();
```

## 气压计

监听大气压变化：

```ts
import { onBarometerChange } from '@nebula-rn/client';

const unsubscribe = onBarometerChange((data) => {
  console.log(`气压: ${data.pressure} hPa`);
});

unsubscribe();
```

气压计不支持自定义采样间隔。

## 回调数据类型

```ts
// 加速计 / 陀螺仪 / 磁力计
type SensorData = {
  x: number;
  y: number;
  z: number;
  timestamp?: number;
};

// 气压计
type BarometerData = {
  pressure: number;
};
```

## 采样间隔

| 传感器 | 默认间隔 | 可自定义 |
|--------|---------|---------|
| 加速计 | 100ms | 是 |
| 陀螺仪 | 100ms | 是 |
| 磁力计 | 100ms | 是 |
| 气压计 | 系统默认 | 否 |

## 完整示例

```tsx
import React, { useState, useEffect } from 'react';
import { StyleSheet, Text, View } from 'react-native';
import { onAccelerometerChange } from '@nebula-rn/client';

export default function SensorDemoPage() {
  const [accel, setAccel] = useState({ x: 0, y: 0, z: 0 });

  useEffect(() => {
    const unsubscribe = onAccelerometerChange((data) => {
      setAccel({ x: data.x, y: data.y, z: data.z });
    }, 200);

    return () => { unsubscribe(); };
  }, []);

  return (
    <View style={styles.container}>
      <Text style={styles.title}>加速计数据</Text>
      <Text>X: {accel.x.toFixed(4)}</Text>
      <Text>Y: {accel.y.toFixed(4)}</Text>
      <Text>Z: {accel.z.toFixed(4)}</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { padding: 20 },
  title: { fontSize: 18, fontWeight: '600', marginBottom: 12 },
});
```

## 注意事项

- 传感器订阅会持续消耗电量，不需要时及时取消
- 在 `useEffect` 的清理函数中调用 `unsubscribe()` 防止内存泄漏
- 高频采样（低于 50ms）会增加 CPU 和电量消耗，按需选择合理间隔
- 传感器可用性取决于设备硬件，部分设备可能不支持气压计
