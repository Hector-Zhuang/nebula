---

`@nebula-rn/sdk` هي الحزمة الأساسية لوقت تشغيل Nebula، وتوفّر أيضًا واجهات تهيئة المضيف (`NebulaAPI`) وواجهات miniapp (`MiniAppAPI` وهو تصدير باسم مستعار من `NebulaAPI`).

**الإصدار:** 0.1.0

**Peer Dependencies:** `react >= 19`، `react-native >= 0.83`

---

## تهيئة المضيف

### NebulaAPI.wrap(options)

دالة HOC لتغليف مكوّن جذر المضيف وتهيئة وقت تشغيل Nebula. عند تركيب المكوّن يتم استدعاء `startApiServer()` تلقائيًا، وإذا كانت قيمة `serverBaseURL` غير فارغة يتم أيضًا استدعاء `setServerBaseURL()`.

| المنصة | الدعم |
|------|------|
| iOS | ✅ |
| Android | ✅ |

```ts
function wrap(options: NebulaHostOptions): <P>(Component: React.ComponentType<P>) => React.ComponentType<P>
```

**المعاملات `NebulaHostOptions`:**

| المعامل | النوع | مطلوب | الافتراضي | الوصف |
|------|------|------|--------|------|
| `hostApis` | `NebulaHostFeature[]` | لا | `[]` | قائمة قدرات المضيف المطلوب تسجيلها في وقت التشغيل. |
| `serverBaseURL` | `string \| null` | لا | `null` | عنوان خدمة موارد miniapp. |

**مثال:**

```tsx
import { NebulaAPI } from '@nebula-rn/sdk';
import { defaultHostApis } from '@nebula-rn/host-apis';

export default NebulaAPI.wrap({
	serverBaseURL: 'https://api.example.com',
	hostApis: defaultHostApis,
})(App);
```

### NebulaAPI.startApiServer()

تشغيل خدمة معالجة رسائل API على جانب المضيف والاستماع لطلبات البروتوكول القادمة من miniapp. عادةً يتم استدعاؤها عبر `wrap()`، والاستدعاء اليدوي آمن ومتكرر (idempotent).

| المنصة | الدعم |
|------|------|
| iOS | ✅ |
| Android | ✅ |

```ts
function startApiServer(): void
```

**أنواع الطلبات المعالجة:**

| نوع الطلب | الوصف |
|-----------|------|
| `getCapabilities` | يعيد الإصدارات وحالة الدعم للـ APIs المسجلة. |
| `getApiDescriptions` | يعيد وصف الوثائق للـ APIs المسجلة. |
| `invoke` | يوجّه التنفيذ إلى الـ handler المناسب. |

**رموز الأخطاء الداخلية:**

| رمز الخطأ | الوصف |
|--------|------|
| `UNSUPPORTED_API` | الـ API غير مسجّل أو غير مدعوم. |
| `INTERNAL_ERROR` | حدث استثناء داخل handler. |

**المعاملات:**

| المعامل | النوع | مطلوب | الافتراضي | الوصف |
|------|------|------|--------|------|
| `appId` | `string` | نعم | — | معرّف miniapp المثبتة. |
| `initialProps` | `Record<string, unknown>` | لا | `{}` | الخصائص الابتدائية للمكوّن الجذري. |
| `versionType` | `'release' \| 'experience'` | لا | `'release'` | الإصدار الذي يُثبت عند عدم التثبيت. |

## الإصدارات والتحديث

### NebulaAPI.checkMiniAppUpdate(appId)

التحقق من وجود تحديث متاح لـ miniapp. يتم جلب `app.json` البعيد ومقارنة الإصدار وفق semver.

| المنصة | الدعم |
|------|------|
| iOS | ✅ |
| Android | ✅ |

```ts
function checkMiniAppUpdate(appId: string): Promise<MiniAppUpdateInfo>
```

**المعاملات:**

| المعامل | النوع | مطلوب | الوصف |
|------|------|------|------|
| `appId` | `string` | نعم | معرّف miniapp المثبتة. |

**الإرجاع `MiniAppUpdateInfo`:**

| الحقل | النوع | الوصف |
|------|------|------|
| `appId` | `string` | معرّف miniapp. |
| `currentVersion` | `string \| null` | الإصدار المثبت. |
| `latestVersion` | `string \| null` | أحدث إصدار بعيد. |
| `hasUpdate` | `boolean` | هل يوجد تحديث متاح. |
| `updateStrategy` | `'auto' \| 'manual'` | استراتيجية التحديث. |
| `mode` | `string \| null` | وضع وقت التشغيل. |
| `sourceUrl` | `string \| null` | عنوان مصدر bundle. |

**حالات `hasUpdate: false`:**
- miniapp غير مثبتة.
- في وضع development.
- لا يوجد `sourceUrl` (تطبيق محلي غير بعيد).
- لا يمكن اشتقاق عنوان manifest.

**منطق مقارنة الإصدار:** تقسيم حسب `.` والمقارنة رقمًا مع افتراض 0 للأجزاء المفقودة.

| `modalProps` | `Record \| (payload, request) => Record` | لا | خصائص إضافية لواجهة Modal. |
| `onBeforeOpen` | `(payload) => Promise<NebulaApiInvokeResult \| null>` | لا | معالجة قبل الفتح (مثل فحص الأذونات). إذا لم تكن `null` يتم تجاوز الـ Modal. |
| `onUnmountErrorMessage` | `string` | لا | رسالة خطأ عند إزالة الـ Modal بشكل غير طبيعي. |
| `version` | `string` | لا | إصدار الـ API. |
| `description` | `NebulaHostApiDescription` | لا | وصف وثائق الـ API. |

## الوحدات الأصلية

يتواصل `@nebula-rn/sdk` مع الطبقة الأصلية عبر `NebulaNativeModule`.

**الأساليب المتزامنة:** `getDeviceInfo()`

**الأساليب غير المتزامنة:** جميع الاستدعاءات الأخرى تعيد Promise.

**ثوابت الإعدادات على المنصة:**

| الإعداد | القيمة الافتراضية في iOS | الوصف |
|------|------------|------|
| الحد الأقصى لعدد miniapps المتزامنة | `3` | أقصى عدد miniapps في الذاكرة في الوقت نفسه. |
| الحد الأقصى لعمق مكدس الصفحات | `10` | أقصى عدد صفحات لكل miniapp. |

**القيم الافتراضية للمهل:**

| العملية | المهلة |
|------|------|
| `invokeHostApi()` | 15000ms |
| `getCapabilities()` | 15000ms (ثابت) |
| `getHostApiDescriptions()` | 15000ms (قابلة للضبط) |
| تنزيل الشبكة (Android) | اتصال 15s + قراءة 15s |
| تنزيل الشبكة (iOS) | URLSession الافتراضي |

**ملخص رموز الخطأ:**

| رمز الخطأ | المنصة | السياق |
|--------|------|------|
| `NO_ACTIVITY` | Android | عدم وجود Activity عند فتح/عرض Modal |
| `NO_ROOT_VC` | iOS | عدم وجود root view controller عند الفتح |
| `OPEN_ERROR` | كل المنصات | خطأ عند فتح miniapp |
| `PRELOAD_ERROR` | كل المنصات | خطأ في التحميل المسبق |
| `INSTALL_ERROR` | كل المنصات | فشل التنزيل أو التحليل |
| `INVALID_SERVER_URL` | كل المنصات | تنسيق URL غير صالح |
| `INVALID_MANIFEST` | كل المنصات | فشل تحليل بيان JSON |
| `INVALID_MODE` | iOS | وضع تشغيل غير صالح |
| `UNSUPPORTED_API` | كل المنصات | API غير مسجّل أو غير مدعوم |
| `INTERNAL_ERROR` | كل المنصات | استثناء داخل handler |
| `PRESENT_HOST_MODAL_ERROR` | Android | فشل عرض Modal |
