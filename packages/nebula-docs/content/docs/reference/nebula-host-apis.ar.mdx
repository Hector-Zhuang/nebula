---
title: "@nebula-rn/host-apis"
description: "مرجع API لحزمة تنفيذ قدرات المضيف الرسمية في Nebula، مع تسجيل جاهز وشرح مفصل لكل API."
---

توفر `@nebula-rn/host-apis` تنفيذات رسمية لقدرات المضيف. يمكن لتطبيق المضيف استخدام هذه الميزات الجاهزة وتسجيلها في وقت التشغيل عبر `NebulaAPI.wrap()`.

**الإصدار:** 0.0.1

---

## بدء سريع

### تسجيل جميع واجهات API الافتراضية

```tsx
import { NebulaAPI } from '@nebula-rn/sdk';
import { defaultHostApis } from '@nebula-rn/host-apis';

export default NebulaAPI.wrap({
	serverBaseURL: 'https://api.example.com',
	hostApis: defaultHostApis,
})(App);
```

### التسجيل حسب الحاجة

```tsx
import { scanCodeHostApi, previewImageHostApi } from '@nebula-rn/host-apis';

NebulaAPI.wrap({
	hostApis: [scanCodeHostApi, previewImageHostApi],
})(App);
```

## التصديرات

| اسم التصدير | النوع | الوصف |
|--------|------|------|
| `defaultHostApis` | `NebulaHostFeature[]` | مصفوفة تتضمن جميع واجهات API الافتراضية. |
| `scanCodeHostApi` | `NebulaHostFeature` | واجهة Modal للمسح. |
| `previewImageHostApi` | `NebulaHostFeature` | واجهة Modal لمعاينة الصور. |
| `coreHostApis` | `NebulaHostFeature[]` | مصفوفة واجهات API الأساسية. |
| `downloadFileHostApi` | `NebulaHostFeature` | تنزيل ملفات (Task API). |
| `downloadFileHost` | `function` | تنزيل ملفات (دالة مباشرة). |
| `uploadFileHostApi` | `NebulaHostFeature` | رفع ملفات (Task API). |
| `uploadFileHost` | `function` | رفع ملفات (دالة مباشرة). |
| `saveMediaHost` | `function` | حفظ الوسائط إلى ألبوم النظام. |

`defaultHostApis` = `[scanCodeHostApi, previewImageHostApi, ...coreHostApis]`

## واجهات Modal

### scanCode

فتح واجهة مسح يديرها المضيف، تدعم QR والباركود.

| المنصة | الدعم |
|------|------|
| iOS | ✅ |
| Android | ✅ |

**اسم API:** `scanCode`

**الإصدار:** 1.0

**Payload:**

| المعامل | النوع | مطلوب | الافتراضي | الوصف |
|------|------|------|--------|------|
| `scanType` | `string[]` | لا | `['qr', 'ean-13', 'code-128']` | أنواع الأكواد المراد التعرف عليها. |
| `onlyFromCamera` | `boolean` | لا | — | استخدام الكاميرا فقط. |

**الإرجاع:**

| الحقل | النوع | الوصف |
|------|------|------|
| `result` | `string \| undefined` | محتوى المسح. |
| `scanType` | `string \| 'unknown'` | نوع الكود المُعرّف. |
| `rawData` | `unknown` | بيانات المسح الخام. |

**متطلبات الأذونات:** إذن الكاميرا.

**الفروق بين المنصات:**

| | iOS | Android |
|--|-----|---------|
| التحقق من الإذن | تحقق مسبق في `onBeforeOpen`، عند عدم الإذن يُعاد `PERMISSION_DENIED` | معالجة تلقائية على مستوى النظام |

**رموز الخطأ:**

| رمز الخطأ | الوصف |
|--------|------|
| `PERMISSION_DENIED` | عدم منح إذن الكاميرا (iOS فقط). |
| `USER_CANCELLED` | أغلق المستخدم واجهة المسح. |
| `UNSUPPORTED_SOURCE` | الجهاز لا يدعم المسح. |
| `SCAN_FAILED` | فشل عملية المسح. |

## الوسائط

### chooseMedia

فتح منتقي الوسائط لاختيار صور/فيديو من الألبوم أو الكاميرا.

| المنصة | الدعم |
|------|------|
| iOS | ✅ |
| Android | ✅ |

**اسم API:** `chooseMedia`

**المهلة:** 120000ms

**Payload:**

| المعامل | النوع | مطلوب | الافتراضي | الوصف |
|------|------|------|--------|------|
| `count` | `number` | لا | `9` | الحد الأقصى للملفات. |
| `mediaType` | `('image' \| 'video' \| 'mix')[]` | لا | `['image', 'video']` | فلترة أنواع الوسائط. |
| `sourceType` | `('album' \| 'camera')[]` | لا | `['album', 'camera']` | فلترة المصدر. |
| `maxDuration` | `number` | لا | `10` | مدة التسجيل القصوى (ثوان). |
| `sizeType` | `('original' \| 'compressed')[]` | لا | `['original', 'compressed']` | خيارات الضغط. |
| `camera` | `'back' \| 'front'` | لا | `'back'` | الكاميرا الافتراضية. |

**الإرجاع:**

| الحقل | النوع | الوصف |
|------|------|------|
| `type` | `'image' \| 'video' \| 'mix'` | نوع الوسائط المختارة. |
| `tempFiles` | `TempFile[]` | قائمة الملفات. |

**حقول `TempFile`:**

| الحقل | النوع | الوصف |
|------|------|------|
| `tempFilePath` | `string` | مسار الملف المؤقت. |
| `size` | `number` | حجم الملف (بايت). |
| `duration` | `number \| undefined` | مدة الفيديو (ثوان). |
| `height` | `number \| undefined` | الارتفاع. |
| `width` | `number \| undefined` | العرض. |
| `thumbTempFilePath` | `string \| undefined` | مسار الصورة المصغرة (فيديو). |
| `fileType` | `'image' \| 'video'` | نوع الملف. |

**جودة الضغط:** `compressed` = 0.8، و`original` = 1.0.

**رموز الخطأ:**

| رمز الخطأ | الوصف |
|--------|------|
| `chooseMedia:fail cancel` | إلغاء المستخدم. |
| `chooseMedia:fail {code}` | خطأ في المنتقي. |

## نقل الملفات (Task API)

تدعم Task API ردود تقدم وإلغاء العمليات. يستدعي `start` ويعيد `taskId`، ويستخدم `abort` للإلغاء.

### downloadFile.start

بدء مهمة تنزيل ملف.

| المنصة | الدعم |
|------|------|
| iOS | ✅ |
| Android | ✅ |

**اسم API:** `downloadFile.start`

**Payload:**

| المعامل | النوع | مطلوب | الافتراضي | الوصف |
|------|------|------|--------|------|
| `url` | `string` | نعم | — | عنوان التنزيل. |
| `header` | `Record<string, string>` | لا | — | ترويسات HTTP مخصّصة. |
| `timeout` | `number` | لا | `60000` | المهلة (ms). |
| `filePath` | `string` | لا | يتم توليده | مسار الحفظ. إذا لم يُقدّم يُحفظ في المسار المؤقت. |

**الإرجاع:**

| الحقل | النوع | الوصف |
|------|------|------|
| `taskId` | `string` | معرّف المهمة. |

**أحداث التقدم (channel: `task.progress`):**

| الحقل | النوع | الوصف |
|------|------|------|
| `progress` | `number` | نسبة التقدم (0-100). |
| `totalBytesWritten` | `number` | البايتات التي تم تنزيلها. |
| `totalBytesExpectedToWrite` | `number` | إجمالي البايتات. |

**أحداث الترويسات (channel: `task.headers`):**

| الحقل | النوع | الوصف |
|------|------|------|
| `header` | `Record<string, string>` | ترويسات الاستجابة. |

**نتيجة الاكتمال:**

```ts
// نجاح
{ ok: true, data: { tempFilePath: string, statusCode: number } }

// فشل
{ ok: false, error: { code: 'DOWNLOAD_FAILED', message: string } }
```

**توليد المسار تلقائيًا:** `${TemporaryDirectoryPath}/${Date.now()}_download`

**التنفيذ:** يعتمد على RNFS.downloadFile.
