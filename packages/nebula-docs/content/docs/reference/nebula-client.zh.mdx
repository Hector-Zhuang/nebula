`@nebula-rn/client` 是小程序开发者的主要 API 包，提供对宿主能力的稳定调用接口。所有 API 通过 Nebula 协议层与宿主通信。

## 扫码

### scanCode(options?)

打开宿主管理的扫码界面，返回扫码结果。扫码成功后自动关闭界面并返回数据；如果失败则抛出异常。

| 平台    | 支持 |
| ------- | ---- |
| iOS     | ✅   |
| Android | ✅   |

```ts
function scanCode(options?: ScanCodeOptions): Promise<ScanCodeData>;
```

**参数 `ScanCodeOptions`：**

| 参数             | 类型       | 必填 | 默认值                         | 描述                                             |
| ---------------- | ---------- | ---- | ------------------------------ | ------------------------------------------------ |
| `scanType`       | `string[]` | 否   | `['qr', 'ean-13', 'code-128']` | 要识别的码类型列表。                             |
| `onlyFromCamera` | `boolean`  | 否   | `false`                        | 设为 `true` 时仅使用相机扫码，不允许从相册选取。 |

**返回值 `ScanCodeData`：**

| 字段       | 类型                  | 描述                                                     |
| ---------- | --------------------- | -------------------------------------------------------- |
| `result`   | `string \| undefined` | 扫码内容字符串。                                         |
| `scanType` | `string`              | 识别到的码类型，如 `'QR_CODE'`。未识别时为 `'unknown'`。 |
| `rawData`  | `unknown`             | 原始扫码数据。                                           |

**超时：** 120000ms

**错误码：**

| 错误码               | 描述                     |
| -------------------- | ------------------------ |
| `PERMISSION_DENIED`  | 相机权限未授权。         |
| `USER_CANCELLED`     | 用户主动关闭了扫码界面。 |
| `UNSUPPORTED_SOURCE` | 请求的扫码来源不可用。   |
| `SCAN_FAILED`        | 扫码过程发生错误。       |

### scanCodeSafe(options?)

与 `scanCode` 功能相同，但不会抛出异常，而是返回 Result 类型。适合需要在调用处统一处理成功和失败的场景。

```ts
function scanCodeSafe(options?: ScanCodeOptions): Promise<ScanCodeResult>;
```

**返回值 `ScanCodeResult`：**

```ts
// 成功
{ ok: true, data: ScanCodeData }

// 失败
{ ok: false, error: { code: ScanCodeErrorCode, message: string } }
```

## 媒体

### chooseMedia(options?)

从相册或相机选择图片/视频文件。

| 平台    | 支持 |
| ------- | ---- |
| iOS     | ✅   |
| Android | ✅   |

```ts
function chooseMedia(options?: ChooseMediaOption): Promise<ChooseMediaResult>;
```

**参数 `ChooseMediaOption`：**

| 参数          | 类型                              | 必填 | 默认值                       | 描述                                                 |
| ------------- | --------------------------------- | ---- | ---------------------------- | ---------------------------------------------------- |
| `count`       | `number`                          | 否   | `9`                          | 最多可选择的文件数量。                               |
| `mediaType`   | `('image' \| 'video' \| 'mix')[]` | 否   | `['image', 'video']`         | 允许的媒体类型。                                     |
| `sourceType`  | `('album' \| 'camera')[]`         | 否   | `['album', 'camera']`        | 文件来源。仅包含 `'camera'` 时直接打开相机。         |
| `maxDuration` | `number`                          | 否   | `10`                         | 录制视频的最大时长（秒）。                           |
| `sizeType`    | `('original' \| 'compressed')[]`  | 否   | `['original', 'compressed']` | 图片尺寸类型。包含 `'compressed'` 时质量压缩为 0.8。 |
| `camera`      | `'back' \| 'front'`               | 否   | `'back'`                     | 默认使用的摄像头方向。                               |

**返回值 `ChooseMediaResult`：**

| 字段        | 类型                          | 描述                 |
| ----------- | ----------------------------- | -------------------- |
| `tempFiles` | `ChooseMediaFile[]`           | 选择的文件列表。     |
| `type`      | `'image' \| 'video' \| 'mix'` | 实际选择的媒体类型。 |

**`ChooseMediaFile` 结构：**

| 字段                | 类型                 | 描述                     |
| ------------------- | -------------------- | ------------------------ |
| `tempFilePath`      | `string`             | 文件的临时本地路径。     |
| `size`              | `number`             | 文件大小（字节）。       |
| `fileType`          | `'image' \| 'video'` | 文件类型。               |
| `duration`          | `number`             | （可选）视频时长（秒）。 |
| `width`             | `number`             | （可选）宽度（像素）。   |
| `height`            | `number`             | （可选）高度（像素）。   |
| `thumbTempFilePath` | `string`             | （可选）视频缩略图路径。 |

**超时：** 120000ms

## 位置

### getLocation(options?)

获取当前设备地理位置。

| 平台    | 支持 | 备注                                                                         |
| ------- | ---- | ---------------------------------------------------------------------------- |
| iOS     | ✅   | 需要在 Info.plist 中配置位置权限。                                           |
| Android | ✅   | 首次调用时自动请求 `ACCESS_FINE_LOCATION` 或 `ACCESS_COARSE_LOCATION` 权限。 |

```ts
function getLocation(options?: GetLocationOption): Promise<GetLocationResult>;
```

**参数 `GetLocationOption`：**

| 参数                     | 类型      | 必填 | 默认值  | 描述                         |
| ------------------------ | --------- | ---- | ------- | ---------------------------- |
| `altitude`               | `boolean` | 否   | `false` | 是否请求海拔数据。           |
| `isHighAccuracy`         | `boolean` | 否   | `false` | 是否使用高精度定位。         |
| `highAccuracyExpireTime` | `number`  | 否   | `10000` | 高精度定位超时时间（毫秒）。 |

**返回值 `GetLocationResult`：**

| 字段                 | 类型     | 描述                 |
| -------------------- | -------- | -------------------- |
| `latitude`           | `number` | 纬度（-90 ~ 90）。   |
| `longitude`          | `number` | 经度（-180 ~ 180）。 |
| `speed`              | `number` | 速度（米/秒）。      |
| `accuracy`           | `number` | 精度（米）。         |
| `altitude`           | `number` | 海拔（米）。         |
| `verticalAccuracy`   | `number` | 垂直精度（米）。     |
| `horizontalAccuracy` | `number` | 水平精度（米）。     |

### onLocationChange(enableHighAccuracy, onSuccess, onError?)

订阅位置变化事件，持续接收位置更新。

| 平台    | 支持 |
| ------- | ---- |
| iOS     | ✅   |
| Android | ✅   |

```ts
function onLocationChange(
  enableHighAccuracy: boolean,
  onSuccess: (data: LocationData) => void,
  onError?: (error: unknown) => void,
): () => void;
```

**参数：**

| 参数                 | 类型                           | 必填 | 默认值 | 描述                                                         |
| -------------------- | ------------------------------ | ---- | ------ | ------------------------------------------------------------ |
| `enableHighAccuracy` | `boolean`                      | 否   | `true` | 是否启用高精度。                                             |
| `onSuccess`          | `(data: LocationData) => void` | 是   | -      | 每次位置更新时调用的回调。接收 `LocationData` 对象作为参数。 |
| `onError`            | `(error: unknown) => void`     | 否   | -      | 位置获取失败时调用的回调。                                   |

**回调参数 `LocationData`：**

| 字段        | 类型             | 描述                               |
| ----------- | ---------------- | ---------------------------------- |
| `latitude`  | `number`         | 纬度。                             |
| `longitude` | `number`         | 经度。                             |
| `accuracy`  | `number`         | 精度（米）。                       |
| `altitude`  | `number \| null` | 海拔（米），不可用时为 `null`。    |
| `speed`     | `number \| null` | 速度（米/秒），不可用时为 `null`。 |
| `timestamp` | `number`         | 时间戳。                           |

**返回值：** `() => void` — 调用此函数取消订阅。

## 文件传输

### downloadFile(options)

下载文件到本地临时路径。返回一个 Task 对象，支持中止下载和监听进度。

| 平台    | 支持 |
| ------- | ---- |
| iOS     | ✅   |
| Android | ✅   |

```ts
function downloadFile(options: DownloadFileOption): DownloadTask;
```

**参数 `DownloadFileOption`：**

| 参数       | 类型                     | 必填 | 默认值  | 描述                                   |
| ---------- | ------------------------ | ---- | ------- | -------------------------------------- |
| `url`      | `string`                 | 是   | -       | 下载地址。                             |
| `header`   | `Record<string, string>` | 否   | -       | 自定义 HTTP 请求头。                   |
| `timeout`  | `number`                 | 否   | `60000` | 超时时间（毫秒）。                     |
| `filePath` | `string`                 | 否   | -       | 指定保存路径。不指定时保存到临时目录。 |

**返回值 `DownloadTask`：**

`DownloadTask` 同时是 Promise 和 Task 对象，可以 `await` 获取结果，也可以调用方法控制下载。

| 方法                           | 描述                               |
| ------------------------------ | ---------------------------------- |
| `abort()`                      | 中止下载。返回 `Promise<void>`。   |
| `onProgressUpdate(callback)`   | 注册下载进度回调。回调参数见下表。 |
| `offProgressUpdate(callback)`  | 取消已注册的进度回调。             |
| `onHeadersReceived(callback)`  | 注册响应头接收回调。               |
| `offHeadersReceived(callback)` | 取消已注册的响应头回调。           |

**进度回调参数 `DownloadProgressRes`：**

| 字段                        | 类型     | 描述                |
| --------------------------- | -------- | ------------------- |
| `progress`                  | `number` | 下载进度（0-100）。 |
| `totalBytesWritten`         | `number` | 已下载字节数。      |
| `totalBytesExpectedToWrite` | `number` | 预期总字节数。      |

**最终返回值 `DownloadFileResult`：**

| 字段           | 类型     | 描述                 |
| -------------- | -------- | -------------------- |
| `tempFilePath` | `string` | 下载文件的本地路径。 |
| `statusCode`   | `number` | HTTP 状态码。        |

### uploadFile(options)

上传本地文件到服务器。返回一个 Task 对象，支持中止上传和监听进度。

## 通用约定

### 超时

| 类别          | 默认超时 |
| ------------- | -------- |
| 常规 API      | 15000ms  |
| 媒体/扫码相关 | 120000ms |
| 文件传输      | 60000ms  |

### 文件路径

- 所有文件路径相对于小程序沙箱目录自动解析
- `/Documents/` 路径映射到 `DocumentDirectoryPath`
- `file://` 协议前缀会被自动去除
- 小程序路径前缀为 `/Documents/MiniApps/{appId}`

### 订阅模式

所有订阅类 API（传感器、网络、位置、截屏）遵循统一模式：

```ts
// 订阅
const unsubscribe = onXxxChange(callback);

// 取消订阅
unsubscribe();
```
