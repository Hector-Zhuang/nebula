`@nebula-rn/sdk` 是 Nebula 的核心运行时包，同时提供宿主初始化 API（`NebulaAPI`）和小程序客户端 API（`MiniAppAPI`，是 `NebulaAPI` 的别名导出）。

**版本：** 0.1.0

**Peer Dependencies：** `react >= 19`，`react-native >= 0.83`

---

## 宿主初始化

### NebulaAPI.wrap(options)

包裹宿主 App 根组件的高阶组件（HOC），初始化 Nebula 运行时。在组件挂载时自动调用 `startApiServer()`，如果 `serverBaseURL` 非空则同时调用 `setServerBaseURL()`。

| 平台    | 支持 |
| ------- | ---- |
| iOS     | ✅   |
| Android | ✅   |

```ts
function wrap(
  options: NebulaHostOptions,
): <P>(Component: React.ComponentType<P>) => React.ComponentType<P>;
```

**参数 `NebulaHostOptions`：**

| 参数            | 类型                  | 必填 | 默认值 | 描述                                |
| --------------- | --------------------- | ---- | ------ | ----------------------------------- |
| `hostApis`      | `NebulaHostFeature[]` | 否   | `[]`   | 要注册到运行时的宿主 API 特性列表。 |
| `serverBaseURL` | `string \| null`      | 否   | `null` | 小程序资源服务的基础 URL。          |

**示例：**

```tsx
import { NebulaAPI } from '@nebula-rn/sdk';
import { defaultHostApis } from '@nebula-rn/host-apis';

export default NebulaAPI.wrap({
  serverBaseURL: 'https://api.example.com',
  hostApis: defaultHostApis,
})(App);
```

### NebulaAPI.startApiServer()

启动宿主侧 API 消息处理服务，监听小程序发来的协议请求。通常由 `wrap()` 自动调用，手动调用时幂等执行。

| 平台    | 支持 |
| ------- | ---- |
| iOS     | ✅   |
| Android | ✅   |

```ts
function startApiServer(): void;
```

**处理的请求类型：**

| 请求 kind            | 描述                                  |
| -------------------- | ------------------------------------- |
| `getCapabilities`    | 返回已注册宿主 API 的版本和支持状态。 |
| `getApiDescriptions` | 返回已注册宿主 API 的文档描述。       |
| `invoke`             | 路由到对应的 API handler 执行。       |

**内部错误码：**

| 错误码            | 描述                        |
| ----------------- | --------------------------- |
| `UNSUPPORTED_API` | 请求的 API 未注册或不支持。 |
| `INTERNAL_ERROR`  | Handler 执行时抛出异常。    |

### NebulaAPI.setServerBaseURL(serverBaseURL)

设置宿主服务的基础 URL，持久化到原生存储。小程序安装和更新时使用此 URL 解析相对路径。

| 平台    | 支持 |
| ------- | ---- |
| iOS     | ✅   |
| Android | ✅   |

```ts
function setServerBaseURL(
  serverBaseURL?: string | null,
): Promise<ServerBaseURLResult>;
```

**参数：**

| 参数            | 类型             | 必填 | 默认值 | 描述                                           |
| --------------- | ---------------- | ---- | ------ | ---------------------------------------------- |
| `serverBaseURL` | `string \| null` | 否   | —      | 合法的 http(s) URL，传 `null` 或空字符串清除。 |

**返回值 `ServerBaseURLResult`：**

| 字段            | 类型             | 描述           |
| --------------- | ---------------- | -------------- |
| `serverBaseURL` | `string \| null` | 已设置的 URL。 |

**错误码：**

| 错误码               | 平台          | 描述               |
| -------------------- | ------------- | ------------------ |
| `INVALID_SERVER_URL` | iOS / Android | URL 格式校验失败。 |

## 小程序安装

### NebulaAPI.installMiniApp(appId, bundleURL)

从远程 URL 下载并安装小程序 bundle（production 模式）。自动获取并存储 `app.json` 清单。

| 平台    | 支持 |
| ------- | ---- |
| iOS     | ✅   |
| Android | ✅   |

```ts
function installMiniApp(
  appId: string,
  bundleURL: string,
): Promise<MiniAppResult>;
```

**参数：**

| 参数        | 类型     | 必填 | 描述                              |
| ----------- | -------- | ---- | --------------------------------- |
| `appId`     | `string` | 是   | 小程序唯一标识。                  |
| `bundleURL` | `string` | 是   | bundle 的远程 URL（http/https）。 |

**返回值 `MiniAppResult`：**

| 字段      | 类型      | 描述           |
| --------- | --------- | -------------- |
| `success` | `boolean` | 安装是否成功。 |
| `appId`   | `string`  | 小程序 ID。    |

**平台差异：**

|             | Android                                     | iOS                                       |
| ----------- | ------------------------------------------- | ----------------------------------------- |
| bundle 路径 | `Files/nebula/{appId}/index.android.bundle` | `Documents/MiniApps/{appId}/index.bundle` |
| 网络超时    | 连接 15s + 读取 15s                         | URLSession 默认                           |
| 清单获取    | 自动替换文件名为 `app.json`                 | 同 Android                                |

**错误码：**

| 错误码          | 描述             |
| --------------- | ---------------- |
| `INSTALL_ERROR` | 下载或解析失败。 |

---

### NebulaAPI.installMiniAppWithBundleURL(appId, bundleURL, connectToURLMetroServer?)

以指定 bundle URL 安装小程序，并用 `connectToURLMetroServer` 决定是否把它当作连接该 URL 的 Metro 开发运行时。

| 平台    | 支持 |
| ------- | ---- |
| iOS     | ✅   |
| Android | ✅   |

```ts
function installMiniAppWithBundleURL(
  appId: string,
  bundleURL: string,
  connectToURLMetroServer?: boolean,
): Promise<MiniAppResult>;
```

**参数：**

| 参数                      | 类型      | 必填 | 描述                                                                      |
| ------------------------- | --------- | ---- | ------------------------------------------------------------------------- |
| `appId`                   | `string`  | 是   | 小程序唯一标识。                                                          |
| `bundleURL`               | `string`  | 是   | bundle 远程 URL。                                                         |
| `connectToURLMetroServer` | `boolean` | 否   | `false` 表示按 production 安装；`true` 表示把该 URL 作为 Metro 开发入口。 |

**返回值 `MiniAppResult`：**

| 字段      | 类型      | 描述                                        |
| --------- | --------- | ------------------------------------------- |
| `success` | `boolean` | 安装是否成功。                              |
| `appId`   | `string`  | 小程序 ID。                                 |
| `mode`    | `string`  | 最终安装态：`development` 或 `production`。 |

**行为差异：**

|                  | `connectToURLMetroServer = true` | `connectToURLMetroServer = false` |
| ---------------- | -------------------------------- | --------------------------------- |
| 安装态           | `development`                    | `production`                      |
| `version`        | `null`（不追踪版本）             | 从清单读取                        |
| `updateStrategy` | 强制 `'manual'`                  | 从清单读取，默认 `'manual'`       |
| Dev URL          | 保存热重载 URL                   | 不保存                            |

**错误码：**

| 错误码          | 描述                       |
| --------------- | -------------------------- |
| `INSTALL_ERROR` | 下载或解析失败。           |
| `INVALID_MODE`  | 模式字符串无效（仅 iOS）。 |

## 小程序打开与预加载

### NebulaAPI.openMiniApp(appId, initialProps?, versionType?)

打开一个已安装的小程序并显示给用户。如果本地尚未安装，会先自动安装指定版本类型，默认安装 `release` 版。如果小程序为 production 模式且 `updateStrategy` 为 `'auto'`，会在打开前自动检查并应用更新（更新失败不阻塞打开）。

| 平台    | 支持 |
| ------- | ---- |
| iOS     | ✅   |
| Android | ✅   |

```ts
function openMiniApp(
  appId: string,
  initialProps?: Record<string, unknown>,
  versionType?: 'release' | 'experience',
): Promise<MiniAppResult>;
```

**参数：**

| 参数           | 类型                        | 必填 | 默认值      | 描述                             |
| -------------- | --------------------------- | ---- | ----------- | -------------------------------- |
| `appId`        | `string`                    | 是   | —           | 已安装的小程序 ID。              |
| `initialProps` | `Record<string, unknown>`   | 否   | `{}`        | 传递给小程序根组件的初始属性。   |
| `versionType`  | `'release' \| 'experience'` | 否   | `'release'` | 未安装时自动安装哪一类云端版本。 |

**返回值 `MiniAppResult`：**

| 字段      | 类型      | 描述           |
| --------- | --------- | -------------- |
| `success` | `boolean` | 打开是否成功。 |
| `appId`   | `string`  | 小程序 ID。    |

**平台差异：**

|                | Android                    | iOS                        |
| -------------- | -------------------------- | -------------------------- |
| 线程模型       | `activity.runOnUiThread()` | `DispatchQueue.main.async` |
| 无 UI 容器错误 | `NO_ACTIVITY`              | `NO_ROOT_VC`               |

**错误码：**

| 错误码        | 平台    | 描述                          |
| ------------- | ------- | ----------------------------- |
| `NO_ACTIVITY` | Android | 找不到当前 Activity。         |
| `NO_ROOT_VC`  | iOS     | 找不到 root view controller。 |
| `OPEN_ERROR`  | 全平台  | 运行时错误。                  |

## 版本与更新

### NebulaAPI.checkMiniAppUpdate(appId)

检查小程序是否有可用更新。通过获取远程 `app.json` 清单，使用 semver 数值段比较版本号。

| 平台    | 支持 |
| ------- | ---- |
| iOS     | ✅   |
| Android | ✅   |

```ts
function checkMiniAppUpdate(appId: string): Promise<MiniAppUpdateInfo>;
```

**参数：**

| 参数    | 类型     | 必填 | 描述                |
| ------- | -------- | ---- | ------------------- |
| `appId` | `string` | 是   | 已安装的小程序 ID。 |

**返回值 `MiniAppUpdateInfo`：**

| 字段             | 类型                 | 描述              |
| ---------------- | -------------------- | ----------------- |
| `appId`          | `string`             | 小程序 ID。       |
| `currentVersion` | `string \| null`     | 当前安装版本。    |
| `latestVersion`  | `string \| null`     | 远程最新版本。    |
| `hasUpdate`      | `boolean`            | 是否有可用更新。  |
| `updateStrategy` | `'auto' \| 'manual'` | 更新策略。        |
| `mode`           | `string \| null`     | 运行时模式。      |
| `sourceUrl`      | `string \| null`     | bundle 来源 URL。 |

**返回 `hasUpdate: false` 的情况：**

- 小程序未安装
- 处于 development 模式
- 没有 `sourceUrl`（非远程应用）
- 无法推导清单 URL

**版本比较逻辑：** 按 `.` 分割为数值段逐段比较，缺失段默认为 0。

## 宿主通信

### MiniAppAPI.invokeHostApi(apiName, payload?, version?, timeoutMs?)

从小程序调用宿主注册的 API。通过 Nebula 协议层（`api.v1`）发送请求并等待响应。

| 平台    | 支持 |
| ------- | ---- |
| iOS     | ✅   |
| Android | ✅   |

```ts
function invokeHostApi<TData = unknown>(
  apiName: string,
  payload?: Record<string, unknown>,
  version?: string,
  timeoutMs?: number,
): Promise<NebulaApiInvokeResult<TData>>;
```

**参数：**

| 参数        | 类型                      | 必填 | 默认值    | 描述                               |
| ----------- | ------------------------- | ---- | --------- | ---------------------------------- |
| `apiName`   | `string`                  | 是   | —         | 要调用的宿主 API 名称。            |
| `payload`   | `Record<string, unknown>` | 否   | `{}`      | 传递给 API handler 的数据。        |
| `version`   | `string`                  | 否   | `'1.0.0'` | 请求的 API 版本。                  |
| `timeoutMs` | `number`                  | 否   | `15000`   | 请求超时（毫秒）。`0` 表示不超时。 |

**返回值 `NebulaApiInvokeResult<TData>`：**

```ts
// 成功
{ ok: true, data: TData }

// 失败
{ ok: false, error: { code: string, message: string, details?: Record<string, unknown> } }
```

**错误码：**

| 错误码            | 描述                 |
| ----------------- | -------------------- |
| `UNSUPPORTED_API` | API 未注册或不支持。 |
| `INTERNAL_ERROR`  | Handler 执行异常。   |

**超时：** 15000ms。超时后请求被清理，Promise 以 `"Timed out waiting for host API: {apiName}"` 拒绝。

## 原生模块

`@nebula-rn/sdk` 通过 `NebulaNativeModule` 与原生层通信。

**同步方法：** `getDeviceInfo()`

**异步方法：** 所有其他原生调用均返回 Promise。

**平台配置常量：**

| 配置             | iOS 默认值 | 描述                           |
| ---------------- | ---------- | ------------------------------ |
| 最大并发小程序数 | `3`        | 内存中同时存在的最大小程序数。 |
| 最大页面栈深度   | `10`       | 单个小程序的最大页面层数。     |

**超时默认值：**

| 操作                       | 超时                |
| -------------------------- | ------------------- |
| `invokeHostApi()`          | 15000ms             |
| `getCapabilities()`        | 15000ms（固定）     |
| `getHostApiDescriptions()` | 15000ms（可配置）   |
| 网络下载（Android）        | 连接 15s + 读取 15s |
| 网络下载（iOS）            | URLSession 默认     |

**错误码总览：**

| 错误码                     | 平台    | 上下文                            |
| -------------------------- | ------- | --------------------------------- |
| `NO_ACTIVITY`              | Android | 打开/弹出 Modal 时找不到 Activity |
| `NO_ROOT_VC`               | iOS     | 打开时找不到 root view controller |
| `OPEN_ERROR`               | 全平台  | 运行时打开小程序错误              |
| `PRELOAD_ERROR`            | 全平台  | 运行时预加载错误                  |
| `INSTALL_ERROR`            | 全平台  | 下载或解析失败                    |
| `INVALID_SERVER_URL`       | 全平台  | URL 格式校验失败                  |
| `INVALID_MANIFEST`         | 全平台  | 清单 JSON 解析失败                |
| `INVALID_MODE`             | iOS     | 运行时模式字符串无效              |
| `UNSUPPORTED_API`          | 全平台  | API 未注册或不支持                |
| `INTERNAL_ERROR`           | 全平台  | Handler 执行异常                  |
| `PRESENT_HOST_MODAL_ERROR` | Android | 弹出 Modal 失败                   |
