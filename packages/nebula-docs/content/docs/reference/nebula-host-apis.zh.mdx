`@nebula-rn/host-apis` 提供了官方的宿主 API 特性实现。宿主 App 可以直接使用这些预构建的特性，通过 `NebulaAPI.wrap()` 注册到运行时。

**版本：** 0.0.1

---

## 快速使用

### 注册所有默认 API

```tsx
import { NebulaAPI } from '@nebula-rn/sdk';
import { defaultHostApis } from '@nebula-rn/host-apis';

export default NebulaAPI.wrap({
  serverBaseURL: 'https://api.example.com',
  hostApis: defaultHostApis,
})(App);
```

### 按需注册

```tsx
import { scanCodeHostApi, previewImageHostApi } from '@nebula-rn/host-apis';

NebulaAPI.wrap({
  hostApis: [scanCodeHostApi, previewImageHostApi],
})(App);
```

## 导出

| 导出名                | 类型                  | 描述                      |
| --------------------- | --------------------- | ------------------------- |
| `defaultHostApis`     | `NebulaHostFeature[]` | 包含所有默认 API 的数组。 |
| `scanCodeHostApi`     | `NebulaHostFeature`   | 扫码 Modal API。          |
| `previewImageHostApi` | `NebulaHostFeature`   | 图片预览 Modal API。      |
| `coreHostApis`        | `NebulaHostFeature[]` | 核心功能 API 数组。       |
| `downloadFileHostApi` | `NebulaHostFeature`   | 文件下载（Task API）。    |
| `downloadFileHost`    | `function`            | 文件下载（纯函数）。      |
| `uploadFileHostApi`   | `NebulaHostFeature`   | 文件上传（Task API）。    |
| `uploadFileHost`      | `function`            | 文件上传（纯函数）。      |
| `saveMediaHost`       | `function`            | 保存媒体到系统相册。      |

`defaultHostApis` = `[scanCodeHostApi, previewImageHostApi, ...coreHostApis]`

## Modal API

### scanCode

打开宿主管理的扫码界面，支持二维码和条形码。

| 平台    | 支持 |
| ------- | ---- |
| iOS     | ✅   |
| Android | ✅   |

**API 名称：** `scanCode`

**版本：** 1.0

**Payload：**

| 参数             | 类型       | 必填 | 默认值                         | 描述             |
| ---------------- | ---------- | ---- | ------------------------------ | ---------------- |
| `scanType`       | `string[]` | 否   | `['qr', 'ean-13', 'code-128']` | 要识别的码类型。 |
| `onlyFromCamera` | `boolean`  | 否   | —                              | 仅使用相机扫码。 |

**返回值：**

| 字段       | 类型                  | 描述             |
| ---------- | --------------------- | ---------------- |
| `result`   | `string \| undefined` | 扫码内容。       |
| `scanType` | `string \| 'unknown'` | 识别到的码类型。 |
| `rawData`  | `unknown`             | 原始扫码数据。   |

**权限要求：** 相机权限。

**平台差异：**

|          | iOS                                                       | Android        |
| -------- | --------------------------------------------------------- | -------------- |
| 权限检查 | `onBeforeOpen` 中主动检查，未授权返回 `PERMISSION_DENIED` | 系统级自动处理 |

**错误码：**

| 错误码               | 描述                       |
| -------------------- | -------------------------- |
| `PERMISSION_DENIED`  | 相机权限未授权（仅 iOS）。 |
| `USER_CANCELLED`     | 用户关闭扫码界面。         |
| `UNSUPPORTED_SOURCE` | 设备不支持扫码。           |
| `SCAN_FAILED`        | 扫码过程失败。             |

## 位置

### getLocation

获取当前地理位置（一次性）。

| 平台    | 支持 |
| ------- | ---- |
| iOS     | ✅   |
| Android | ✅   |

**API 名称：** `getLocation`

| 参数                     | 类型      | 必填 | 默认值  | 描述               |
| ------------------------ | --------- | ---- | ------- | ------------------ |
| `isHighAccuracy`         | `boolean` | 否   | —       | 是否启用高精度。   |
| `highAccuracyExpireTime` | `number`  | 否   | `10000` | 高精度超时（ms）。 |

| 字段                 | 类型     | 描述          |

## 媒体

### chooseMedia

打开媒体选择器，从相册或相机获取图片/视频。

| 平台    | 支持 |
| ------- | ---- |
| iOS     | ✅   |
| Android | ✅   |

**API 名称：** `chooseMedia`

**超时：** 120000ms

**Payload：**

| 参数          | 类型                              | 必填 | 默认值                       | 描述                 |
| ------------- | --------------------------------- | ---- | ---------------------------- | -------------------- |
| `count`       | `number`                          | 否   | `9`                          | 最大可选数量。       |
| `mediaType`   | `('image' \| 'video' \| 'mix')[]` | 否   | `['image', 'video']`         | 媒体类型过滤。       |
| `sourceType`  | `('album' \| 'camera')[]`         | 否   | `['album', 'camera']`        | 来源过滤。           |
| `maxDuration` | `number`                          | 否   | `10`                         | 录制最大时长（秒）。 |
| `sizeType`    | `('original' \| 'compressed')[]`  | 否   | `['original', 'compressed']` | 压缩选项。           |
| `camera`      | `'back' \| 'front'`               | 否   | `'back'`                     | 默认摄像头。         |

**返回值：**

| 字段        | 类型                          | 描述           |
| ----------- | ----------------------------- | -------------- |
| `type`      | `'image' \| 'video' \| 'mix'` | 所选媒体类型。 |
| `tempFiles` | `TempFile[]`                  | 文件列表。     |

**`TempFile` 字段：**

| 字段                | 类型                  | 描述                 |
| ------------------- | --------------------- | -------------------- |
| `tempFilePath`      | `string`              | 临时文件路径。       |
| `size`              | `number`              | 文件大小（字节）。   |
| `duration`          | `number \| undefined` | 视频时长（秒）。     |
| `height`            | `number \| undefined` | 高度。               |
| `width`             | `number \| undefined` | 宽度。               |
| `thumbTempFilePath` | `string \| undefined` | 缩略图路径（视频）。 |
| `fileType`          | `'image' \| 'video'`  | 文件类型。           |

**压缩质量：** `compressed` 为 0.8，`original` 为 1.0。

**错误码：**

| 错误码                    | 描述         |
| ------------------------- | ------------ |
| `chooseMedia:fail cancel` | 用户取消。   |
| `chooseMedia:fail {code}` | 选择器错误。 |

## 文件传输（Task API）

Task API 支持进度回调和中止操作。调用 `start` 返回 `taskId`，通过 `abort` 取消任务。

### downloadFile.start

开始文件下载任务。

| 平台    | 支持 |
| ------- | ---- |
| iOS     | ✅   |
| Android | ✅   |

**API 名称：** `downloadFile.start`

**Payload：**

| 参数       | 类型                     | 必填 | 默认值   | 描述                               |
| ---------- | ------------------------ | ---- | -------- | ---------------------------------- |
| `url`      | `string`                 | 是   | —        | 下载 URL。                         |
| `header`   | `Record<string, string>` | 否   | —        | 自定义 HTTP 请求头。               |
| `timeout`  | `number`                 | 否   | `60000`  | 超时（ms）。                       |
| `filePath` | `string`                 | 否   | 自动生成 | 保存路径。不提供时保存到临时目录。 |

**返回值：**

| 字段     | 类型     | 描述      |
| -------- | -------- | --------- |
| `taskId` | `string` | 任务 ID。 |

**进度事件（channel: `task.progress`）：**

| 字段                        | 类型     | 描述                  |
| --------------------------- | -------- | --------------------- |
| `progress`                  | `number` | 进度百分比（0-100）。 |
| `totalBytesWritten`         | `number` | 已下载字节数。        |
| `totalBytesExpectedToWrite` | `number` | 总字节数。            |

**Header 事件（channel: `task.headers`）：**

| 字段     | 类型                     | 描述     |
| -------- | ------------------------ | -------- |
| `header` | `Record<string, string>` | 响应头。 |

**完成结果：**

```ts
// 成功
{ ok: true, data: { tempFilePath: string, statusCode: number } }

// 失败
{ ok: false, error: { code: 'DOWNLOAD_FAILED', message: string } }
```

**自动路径生成：** `${TemporaryDirectoryPath}/${Date.now()}_download`

**实现：** 基于 RNFS.downloadFile。
