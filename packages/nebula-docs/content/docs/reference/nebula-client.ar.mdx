`@nebula-rn/client` هي الحزمة الرئيسية لمطوري miniapp وتوفّر واجهات مستقرة لاستدعاء قدرات المضيف. جميع الـ APIs تتواصل مع المضيف عبر طبقة بروتوكول Nebula.

## المسح

### scanCode(options?)

فتح واجهة المسح المُدارة من المضيف وإرجاع نتيجة المسح. عند النجاح تُغلق الواجهة تلقائيًا ويُعاد الناتج؛ وعند الفشل يُرمى استثناء.

| المنصة | الدعم |
|------|------|
| iOS | ✅ |
| Android | ✅ |

```ts
function scanCode(options?: ScanCodeOptions): Promise<ScanCodeData>
```

**المعاملات `ScanCodeOptions`:**

| المعامل | النوع | مطلوب | الافتراضي | الوصف |
|------|------|------|--------|------|
| `scanType` | `string[]` | لا | `['qr', 'ean-13', 'code-128']` | قائمة أنواع الأكواد المراد التعرف عليها. |
| `onlyFromCamera` | `boolean` | لا | `false` | عند `true` يستخدم الكاميرا فقط ولا يسمح بالاختيار من الألبوم. |

**الإرجاع `ScanCodeData`:**

| الحقل | النوع | الوصف |
|------|------|------|
| `result` | `string \| undefined` | نص نتيجة المسح. |
| `scanType` | `string` | نوع الكود المُعرّف مثل `'QR_CODE'`، وعند عدم التعرف تكون `'unknown'`. |
| `rawData` | `unknown` | بيانات المسح الخام. |

**المهلة:** 120000ms

**رموز الخطأ:**

| رمز الخطأ | الوصف |
|--------|------|
| `PERMISSION_DENIED` | إذن الكاميرا غير مُصرّح به. |
| `USER_CANCELLED` | أغلق المستخدم واجهة المسح. |
| `UNSUPPORTED_SOURCE` | مصدر المسح غير مدعوم. |
| `SCAN_FAILED` | حدث خطأ أثناء المسح. |

### scanCodeSafe(options?)

نفس وظيفة `scanCode` لكنها لا ترمي استثناء، بل تعيد نوع Result. مناسبة للحالات التي تُدار فيها الأخطاء في مكان واحد.

```ts
function scanCodeSafe(options?: ScanCodeOptions): Promise<ScanCodeResult>
```

**الإرجاع `ScanCodeResult`:**

```ts
// نجاح
{ ok: true, data: ScanCodeData }

// فشل
{ ok: false, error: { code: ScanCodeErrorCode, message: string } }
```

## نقل الملفات

### downloadFile(options)

تنزيل ملف إلى مسار مؤقت محلي. يعيد كائن Task يدعم الإيقاف والمتابعة.

| المنصة | الدعم |
|------|------|
| iOS | ✅ |
| Android | ✅ |

```ts
function downloadFile(options: DownloadFileOption): DownloadTask
```

**المعاملات `DownloadFileOption`:**

| المعامل | النوع | مطلوب | الافتراضي | الوصف |
|------|------|------|--------|------|
| `url` | `string` | نعم | - | عنوان التنزيل. |
| `header` | `Record<string, string>` | لا | - | ترويسات HTTP مخصّصة. |
| `timeout` | `number` | لا | `60000` | المهلة (ms). |
| `filePath` | `string` | لا | - | مسار الحفظ. إذا لم يُقدّم يُحفظ في المسار المؤقت. |

**الإرجاع `DownloadTask`:**

`DownloadTask` هو Promise وكائن Task معًا، يمكن `await` للحصول على النتيجة أو التحكم عبر الدوال.

| الطريقة | الوصف |
|------|------|
| `abort()` | إلغاء التنزيل. يعيد `Promise<void>`. |
| `onProgressUpdate(callback)` | تسجيل رد تقدم التنزيل. |
| `offProgressUpdate(callback)` | إلغاء رد التقدم. |
| `onHeadersReceived(callback)` | تسجيل رد استقبال الترويسات. |
| `offHeadersReceived(callback)` | إلغاء رد الترويسات. |

**معاملات رد التقدم `DownloadProgressRes`:**

| الحقل | النوع | الوصف |
|------|------|------|
| `progress` | `number` | نسبة التقدم (0-100). |
| `totalBytesWritten` | `number` | البايتات المنزلة. |
| `totalBytesExpectedToWrite` | `number` | إجمالي البايتات المتوقعة. |

**الإرجاع النهائي `DownloadFileResult`:**

| الحقل | النوع | الوصف |
|------|------|------|
| `tempFilePath` | `string` | مسار الملف بعد التنزيل. |
| `statusCode` | `number` | رمز حالة HTTP. |

## اتفاقيات عامة

### المهل

| الفئة | المهلة الافتراضية |
|------|---------|
| APIs العامة | 15000ms |
| الوسائط/المسح | 120000ms |

### مسارات الملفات

- تُحل جميع المسارات نسبةً إلى صندوق miniapp تلقائيًا.
- مسار `/Documents/` يُطابق `DocumentDirectoryPath`.
- يتم إزالة بادئة بروتوكول `file://` تلقائيًا.
- مسار miniapp هو `/Documents/MiniApps/{appId}`.

### نمط الاشتراك

جميع واجهات الاشتراك (المستشعرات، الشبكة، الموقع، لقطات الشاشة) تتبع نفس النمط:

```ts
// الاشتراك
const unsubscribe = onXxxChange(callback);

// إلغاء الاشتراك
unsubscribe();
```
