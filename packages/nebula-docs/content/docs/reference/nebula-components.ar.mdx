## Camera

مكوّن كاميرا يدعم التصوير ووضع المسح. مبني على `react-native-vision-camera`.

| المنصة | الدعم |
|------|------|
| iOS | ✅ |
| Android | ✅ |

```tsx
import { Camera } from '@nebula-rn/components';
```

**مثال:**

```tsx
import { useState } from 'react';
import { Alert, View } from 'react-native';
import { Camera } from '@nebula-rn/components';

export default function ScanCodeDemo() {
	const [mode, setMode] = useState<'normal' | 'scanCode'>('scanCode');

	return (
		<View style={{ height: 240, borderRadius: 12, overflow: 'hidden' }}>
			<Camera
				mode={mode}
				devicePosition="back"
				flash="auto"
				onScanCode={event => {
					Alert.alert('نتيجة المسح', event.result);
					setMode('normal');
				}}
				onError={error => {
					Alert.alert('خطأ في الكاميرا', error.message);
				}}
			/>
		</View>
	);
}
```

**Props:**

| المعامل | النوع | مطلوب | الافتراضي | الوصف |
|------|------|------|--------|------|
| `id` | `string` | لا | — | معرّف المكوّن. |
| `className` | `string` | لا | — | اسم فئة CSS. |
| `style` | `StyleProp<ViewStyle>` | لا | — | نمط مخصّص. |
| `mode` | `'normal' \| 'scanCode'` | لا | `'normal'` | وضع الكاميرا. يفعّل `'scanCode'` وضع التعرف على الأكواد. |
| `resolution` | `'low' \| 'medium' \| 'high'` | لا | — | دقة الكاميرا. |
| `devicePosition` | `'front' \| 'back'` | لا | `'back'` | الكاميرا الأمامية/الخلفية. |
| `flash` | `'auto' \| 'on' \| 'off' \| 'torch'` | لا | — | وضع الفلاش. |

**الأحداث:**

| الحدث | النوع | الوصف |
|------|------|------|
| `onInitDone` | `(event: CameraInitEventDetail) => void` | اكتمال تهيئة الكاميرا. |
| `onReady` | `(event: CameraInitEventDetail) => void` | الكاميرا جاهزة. |
| `onScanCode` | `(event: CameraScanCodeEventDetail) => void` | نجاح المسح (فقط عند `mode='scanCode'`). |
| `onError` | `(error: CameraError) => void` | حدث خطأ. |

**`CameraInitEventDetail`:**

| الحقل | النوع | الوصف |
|------|------|------|
| `maxZoom` | `number` | أقصى درجة تقريب يدعمها الجهاز. |

**`CameraScanCodeEventDetail`:**

| الحقل | النوع | الوصف |
|------|------|------|
| `result` | `string` | نص نتيجة المسح. |
| `fullResult` | `string` | نتيجة المسح الكاملة. |
| `rawData` | `string` | البيانات الخام. |
| `charSet` | `string` | ترميز الحروف. |
| `type` | `CodeType \| 'unknown'` | نوع الكود (مثل QR أو EAN-13). |

**`CameraError`:**

| الحقل | النوع | الوصف |
|------|------|------|
| `message` | `string` | رسالة الخطأ. |
| `code` | `string \| undefined` | رمز الخطأ مثل `'PERMISSION_DENIED'` أو `'PERMISSION_ERROR'`. |
| `nativeError` | `unknown` | كائن الخطأ الأصلي. |

**متطلبات الأذونات:** إذن الكاميرا (يُطلب تلقائيًا عند تركيب المكوّن).

**الأبعاد الافتراضية:** 300x300 مع `overflow: hidden` وخلفية سوداء.

**أنواع الأكواد المدعومة:** QR Code، وباركود EAN-13.

**الاعتماد الأصلي:** `react-native-vision-camera` v4.7.3

## Progress

مكوّن شريط تقدم يدعم الحركة.

| المنصة | الدعم |
|------|------|
| iOS | ✅ |
| Android | ✅ |

```tsx
import { Progress } from '@nebula-rn/components';
```

**مثال:**

```tsx
import { View } from 'react-native';
import { Progress } from '@nebula-rn/components';

export default function UploadProgress() {
	return (
		<View style={{ gap: 12 }}>
			<Progress percent={32} showInfo />
			<Progress
				percent={76}
				active
				activeMode="forwards"
				strokeWidth={8}
				borderRadius={999}
				activeColor="#2563eb"
				backgroundColor="#dbeafe"
			/>
		</View>
	);
}
```

**Props:**

| المعامل | النوع | مطلوب | الافتراضي | الوصف |
|------|------|------|--------|------|
| `percent` | `number` | نعم | — | نسبة التقدم (0-100). |
| `showInfo` | `boolean` | لا | `false` | عرض النسبة على اليمين. |
| `strokeWidth` | `number \| string` | لا | `6` | ارتفاع شريط التقدم (px). |
| `activeColor` | `string` | لا | `'#09BB07'` | لون الجزء المنجَز. |
| `backgroundColor` | `string` | لا | `'#EBEBEB'` | لون الجزء غير المنجَز. |
| `borderRadius` | `number \| string` | لا | `0` | نصف قطر الحواف. |
| `fontSize` | `number \| string` | لا | — | حجم نص النسبة. |
| `active` | `boolean` | لا | — | تفعيل الحركة. |
| `activeMode` | `'backwards' \| 'forwards'` | لا | `'backwards'` | نمط الحركة. |
| `style` | `StyleProp<ViewStyle>` | لا | — | نمط مخصّص. |

**الأحداث:**

| الحدث | النوع | الوصف |
|------|------|------|
| `onActiveEnd` | `(event: { percent: number }) => void` | انتهاء حركة التقدم. |

**أنماط الحركة:**

| النمط | السلوك |
|------|------|
| `backwards` | يعود إلى الصفر ثم يتحرك إلى القيمة الهدف. |
| `forwards` | يتحرك من القيمة الحالية إلى الهدف. |

**مدة الحركة:** `(percent / 100) * 1000` مللي ثانية مع تسارع خطي.

## WebView

مكوّن لعرض محتوى الويب المضمّن، يوسّع قدرات `react-native-webview` بالكامل.

| المنصة | الدعم |
|------|------|
| iOS | ✅ |
| Android | ✅ |

```tsx
import { WebView } from '@nebula-rn/components';
```

**مثال:**

```tsx
import { Alert } from 'react-native';
import { WebView } from '@nebula-rn/components';

const html = `
	<html>
		<body style="font-family: -apple-system; padding: 24px;">
			<h2>محتوى HTML محلي</h2>
			<button onclick="window.ReactNativeWebView.postMessage('clicked')">
				إرسال رسالة إلى miniapp
			</button>
		</body>
	</html>
`;

export default function EmbeddedPage() {
	return (
		<WebView
			html={html}
			style={{ height: 320, borderRadius: 12, overflow: 'hidden' }}
			onMessage={event => {
				Alert.alert('تم استلام الرسالة', event.nativeEvent.data);
			}}
		/>
	);
}
```

**Props:**

| المعامل | النوع | مطلوب | الوصف |
|------|------|------|------|
| `src` | `string` | لا | URL المراد تحميله. |
| `html` | `string` | لا | محتوى HTML المراد عرضه. عند توفيره يتقدّم على `src`. |
| `style` | `StyleProp<ViewStyle>` | لا | نمط مخصّص. |
| `...rest` | `RNWebViewProps` | لا | كل Props الأصلية في `react-native-webview`. |

**الإعدادات الافتراضية:**
- `originWhitelist`: `['*']` (السماح بكل المصادر).

**الاعتماد الأصلي:** `react-native-webview`
