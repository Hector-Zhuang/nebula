---

Nebula 小程序使用页面栈模型管理多页面导航。所有导航操作通过 `Miniapp` 对象调用。

## 页面地址格式

对小程序开发者来说，推荐直接使用**当前小程序内的相对页面路径**：

```
/detail?id=123
/result?status=success
/components/media?autoplay=true
```

其中：

- `pagePath`：对应 `app.json` 中 `pages` 数组声明的页面路径
- `queryParams`：查询参数，自动注入为页面组件的 props

<Warning title="底层协议说明">
  Nebula 底层会使用 `nebula://` 协议来描述页面跳转的目标和参数等信息。

  这属于运行时内部实现，未来可能发生变化，因此当前不会把这套协议细节写入本章节文档。

  即使你是 Host 开发者，也不推荐直接依赖这套协议字符串，请优先使用 Nebula SDK 提供的导航 API。
</Warning>

## 页面栈模型

Nebula 使用页面栈管理当前小程序的所有活跃页面：

```
                    ┌─────────┐
navigateTo ──────►  │ Page C  │  ◄── 栈顶（当前显示）
                    ├─────────┤
                    │ Page B  │
                    ├─────────┤
                    │ Page A  │  ◄── 栈底（首页）
                    └─────────┘
```

## 导航方法

### navigateTo — 打开新页面

将新页面推入栈顶，保留当前页面。用户可以通过返回按钮回到当前页面。

```ts
import { Miniapp } from '@nebula-rn/sdk';

await Miniapp.navigateTo('/detail?id=123');
```

```
Before:  [Home]
After:   [Home, Detail]
                  ↑ 当前显示
```

### redirectTo — 替换当前页面

关闭当前页面，在栈中替换为新页面。用户无法返回被替换的页面。

```ts
await Miniapp.redirectTo('/result?status=success');
```

```
Before:  [Home, Detail]
After:   [Home, Result]
                ↑ Detail 被替换
```

### reLaunch — 重启动

清空整个页面栈，打开一个新页面。适用于跳转到完全无关的流程。

```ts
await Miniapp.reLaunch('/home');
```

```
Before:  [Home, List, Detail, Edit]
After:   [Home]
```

### navigateBack — 返回

从栈中弹出指定数量的页面。默认弹出 1 个（返回上一页）。

```ts
// 返回上一页
await Miniapp.navigateBack(1);

// 返回两级
await Miniapp.navigateBack(2);
```

```
Before:       [Home, List, Detail]
Back(1):      [Home, List]
Back(2) 起:   [Home]
```

## 参数传递

### URL 查询参数 → 组件 Props

导航 URL 中的查询参数会自动注入为目标页面组件的 props：

```ts
// 发起导航
Miniapp.navigateTo('/detail?id=123&from=list');
```

```tsx
// detail/index.tsx — 目标页面
export default function DetailPage(props) {
  // props.id === '123'
  // props.from === 'list'
  const itemId = props?.id;
  const source = props?.from;

  return <Text>Item: {itemId}, from: {source}</Text>;
}
```

### 在 usePageOnLoad 中获取参数

也可以通过 `usePageOnLoad` 的回调参数获取：

```ts
import { usePageOnLoad } from '@nebula-rn/sdk';

usePageOnLoad((params) => {
  // params: Record<string, unknown>
  console.log(params.id);   // '123'
  console.log(params.from); // 'list'
});
```

### 编码注意事项

传递中文或特殊字符时需要 URL 编码：

```ts
const city = '北京';
Miniapp.navigateTo(
  `/weather?city=${encodeURIComponent(city)}`
);

// 目标页面
const city = decodeURIComponent(String(props?.city)); // '北京'
```

## 返回值

所有导航方法返回 `Promise<{ errMsg: string }>`：

```ts
const result = await Miniapp.navigateTo('/detail');
// result.errMsg === 'navigateTo:ok'

// 失败时
// result.errMsg === 'navigateTo:fail page not found'
```

## 页面样式动态修改

在页面内可以动态修改导航栏和页面样式：

```ts
// 修改导航栏标题
await Miniapp.setNavigationBarTitle('新标题');

// 修改导航栏颜色
await Miniapp.setNavigationBarColor({
  backgroundColor: '#1e40af',
  frontColor: '#ffffff',
});

// 修改页面样式
await Miniapp.setPageStyle({
  backgroundColor: '#0f172a',
  navigationStyle: 'custom', // 隐藏系统导航栏
});
```

## 完整示例

```tsx
import React, { useState } from 'react';
import { Button, ScrollView, StyleSheet, Text, View } from 'react-native';
import { Miniapp, usePageOnLoad } from '@nebula-rn/sdk';

export default function ListPage(props) {
  const [items] = useState(['Item A', 'Item B', 'Item C']);

  usePageOnLoad((params) => {
    console.log('ListPage loaded, category:', params.category);
  });

  const openDetail = (id: string) => {
    Miniapp.navigateTo(
      `/detail?id=${id}&from=list`,
    );
  };

  const goHome = () => {
    Miniapp.reLaunch('/home');
  };

  return (
    <ScrollView contentContainerStyle={styles.container}>
      {items.map((item, i) => (
        <Button
          key={i}
          title={item}
          onPress={() => openDetail(String(i))}
        />
      ))}
      <Button title="回到首页" onPress={goHome} />
    </ScrollView>
  );
}

const styles = StyleSheet.create({
  container: { padding: 20 },
});
```

## 注意事项

- 所有页面必须在 `app.json` 的 `pages` 数组中声明才能导航
- 查询参数值都是字符串类型，使用前需要做类型转换
- `navigateBack` 的 `delta` 不能超过当前栈深度
- `redirectTo` 会触发当前页面的 `onUnload` 事件
- `reLaunch` 会触发所有被清除页面的 `onUnload` 事件
