---
title: 小程序目录结构
description: Nebula 小程序的标准目录结构及各文件的作用。
---

一个标准的 Nebula 小程序项目结构如下：

```
my-miniapp/
├── app.json                  # 小程序全局配置（manifest）
├── package.json              # 项目依赖和脚本
├── src/
│   └── pages/                # 页面目录
│       ├── home/
│       │   ├── index.tsx     # 页面组件
│       │   └── page.config.ts # 页面级配置
│       ├── detail/
│       │   ├── index.tsx
│       │   └── page.config.ts
│       └── settings/
│           ├── index.tsx
│           └── page.config.ts
└── build/                    # 构建输出（自动生成）
    ├── main.jsbundle          # 打包后的 JavaScript bundle
    └── app.json               # 生成的 manifest 文件
```

## 文件说明

### `app.json` - 全局配置

小程序的全局配置文件，定义了应用 ID、页面列表、窗口样式等：

```json
{
  "appId": "my-miniapp",
  "updateStrategy": "manual",
  "pages": ["home", "detail", "settings"],
  "entryPagePath": "/home",
  "window": {
    "backgroundColor": "#f8fafc",
    "navigationBarBackgroundColor": "#ffffff",
    "navigationBarTextColor": "#0f172a",
    "visualEffectInBackground": "none"
  }
}
```

详见 [小程序配置](/docs/miniapp/configuration) 文档。

### `package.json`

```json
{
  "name": "@my-org/my-miniapp",
  "private": true,
  "version": "0.0.1",
  "dependencies": {
    "@nebula-rn/client": "*",
    "@nebula-rn/components": "*",
    "@nebula-rn/sdk": "*",
    "react": "19.2.0",
    "react-native": "0.83.1"
  },
  "scripts": {
    "dev": "nebula miniapp dev",
    "build": "nebula miniapp build",
    "upload": "nebula miniapp upload"
  }
}
```

### `src/pages/` - 页面目录

每个页面是一个独立的目录，包含页面组件和可选的页面配置文件。

#### 页面组件（`index.tsx`）

页面组件是一个标准的 React 组件：

```tsx
import { View, Text } from 'react-native';

export default function HomePage() {
  return (
    <View>
      <Text>Hello Nebula</Text>
    </View>
  );
}
```

#### 页面配置（`page.config.ts`）

使用 `definePageConfig` 定义页面级别的配置，会覆盖 `app.json` 中的全局窗口配置：

```ts
import { definePageConfig } from '@nebula-rn/sdk';

export default definePageConfig({
  route: '/home',
  backgroundColor: '#f0f9ff',
  navigationBarBackgroundColor: '#ffffff',
  navigationBarTextColor: '#0f172a',
  navigationBarTitleText: '首页',
  navigationStyle: 'default',
  visualEffectInBackground: 'blur', // 仅 iOS
});
```

### `build/` - 构建输出

执行 `nebula miniapp build` 后自动生成，包含：

- `main.jsbundle`：Metro 打包生成的 JavaScript bundle，包含所有页面和依赖
- `app.json`：基于源码中的配置生成的最终 manifest 文件

### 嵌套页面

页面可以使用嵌套目录来组织：

```
src/pages/
├── home/
├── components/
│   ├── media/
│   │   ├── index.tsx
│   │   └── page.config.ts
│   ├── swiper/
│   └── picker/
└── api-tests/
```

在 `app.json` 中使用路径引用：

```json
{
  "pages": [
    "home",
    "components/media",
    "components/swiper",
    "components/picker"
  ]
}
```
