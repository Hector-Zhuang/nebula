تستخدم Nebula نموذج مكدس الصفحات لإدارة التنقل متعدد الصفحات. تتم جميع عمليات التنقل عبر كائن `Miniapp`.

## صيغة عنوان الصفحة

بالنسبة لمطوري miniapp، يُنصح باستخدام **المسار النسبي داخل miniapp نفسها**:

```
/detail?id=123
/result?status=success
/components/media?autoplay=true
```

حيث:

- `pagePath`: مسار الصفحة المعلن داخل مصفوفة `pages` في `app.json`
- `queryParams`: معاملات الاستعلام التي تُحقن تلقائيًا كـ props لصفحة الوجهة

<Warning title="تفاصيل البروتوكول الداخلي">
  تستخدم Nebula داخليًا البروتوكول `nebula://` لوصف أهداف التنقل والمعاملات.

  هذا تفصيل داخلي وقد يتغير مستقبلًا، لذلك لا يتم توثيقه كنموذج تنقل أساسي هنا.

  حتى بالنسبة لمطوري Host، لا يُنصح بالاعتماد على هذا البروتوكول مباشرة، ويفضّل استخدام واجهات التنقل في Nebula SDK.
</Warning>

## نموذج مكدس الصفحات

تحتفظ Nebula بمكدس للصفحات النشطة داخل miniapp الحالية:

```
                    ┌─────────┐
navigateTo ──────►  │ Page C  │  ◄── أعلى المكدس (المعروضة)
                    ├─────────┤
                    │ Page B  │
                    ├─────────┤
                    │ Page A  │  ◄── أسفل المكدس (الرئيسية)
                    └─────────┘
```

## طرق التنقل

### navigateTo — فتح صفحة جديدة

تدفع صفحة جديدة إلى أعلى المكدس مع الإبقاء على الصفحة الحالية. يمكن للمستخدم العودة بزر الرجوع.

```ts
import { Miniapp } from '@nebula-rn/sdk';

await Miniapp.navigateTo('/detail?id=123');
```

```
Before:  [Home]
After:   [Home, Detail]
                  ↑ الحالية
```

### redirectTo — استبدال الصفحة الحالية

تغلق الصفحة الحالية وتستبدلها بصفحة جديدة داخل المكدس. لا يمكن العودة إلى الصفحة المستبدلة.

```ts
await Miniapp.redirectTo('/result?status=success');
```

```
Before:  [Home, Detail]
After:   [Home, Result]
                ↑ Detail تم استبدالها
```

### reLaunch — إعادة تشغيل

يمسح مكدس الصفحات بالكامل ويفتح صفحة جديدة. مناسب للانتقال إلى تدفق مختلف تمامًا.

```ts
await Miniapp.reLaunch('/home');
```

```
Before:  [Home, List, Detail, Edit]
After:   [Home]
```

### navigateBack — الرجوع

يحذف عددًا محددًا من الصفحات من المكدس. القيمة الافتراضية هي 1 (الرجوع لصفحة واحدة).

```ts
// الرجوع لصفحة واحدة
await Miniapp.navigateBack(1);

// الرجوع لصفحتين
await Miniapp.navigateBack(2);
```

```
Before:       [Home, List, Detail]
Back(1):      [Home, List]
Back(2) من:   [Home]
```

## تمرير المعاملات

### معاملات URL → props الصفحة

تُحقن معاملات الاستعلام في عنوان التنقل كـ props لصفحة الوجهة:

```ts
Miniapp.navigateTo('/detail?id=123&from=list');
```

```tsx
export default function DetailPage(props) {
  const itemId = props?.id;
  const source = props?.from;

  return <Text>Item: {itemId}, from: {source}</Text>;
}
```

### قراءة المعاملات في `usePageOnLoad`

يمكنك أيضًا قراءتها عبر وسيط `usePageOnLoad`:

```ts
import { usePageOnLoad } from '@nebula-rn/sdk';

usePageOnLoad((params) => {
  console.log(params.id);
  console.log(params.from);
});
```

### ملاحظات الترميز

عند تمرير أحرف خاصة أو غير لاتينية يجب استخدام ترميز URL:

```ts
const city = '多伦多'; // Toronto in Chinese
Miniapp.navigateTo(
  `/weather?city=${encodeURIComponent(city)}`,
);
```

```ts
const city = decodeURIComponent(String(props?.city));
```

## قيم الإرجاع

جميع طرق التنقل تعيد `Promise<{ errMsg: string }>`:

```ts
const result = await Miniapp.navigateTo('/detail');
// result.errMsg === 'navigateTo:ok'

// عند الفشل
// result.errMsg === 'navigateTo:fail page not found'
```

## تعديل نمط الصفحة ديناميكيًا

يمكن تعديل شريط التنقل ونمط الصفحة أثناء العرض:

```ts
// تعديل عنوان شريط التنقل
await Miniapp.setNavigationBarTitle('عنوان جديد');

// تعديل لون شريط التنقل
await Miniapp.setNavigationBarColor({
  backgroundColor: '#1e40af',
  frontColor: '#ffffff',
});

// تعديل نمط الصفحة
await Miniapp.setPageStyle({
  backgroundColor: '#0f172a',
  navigationStyle: 'custom', // إخفاء شريط التنقل الافتراضي
});
```

## مثال كامل

```tsx
import React, { useState } from 'react';
import { Button, ScrollView, StyleSheet, Text, View } from 'react-native';
import { Miniapp, usePageOnLoad } from '@nebula-rn/sdk';

export default function ListPage(props) {
  const [items] = useState(['Item A', 'Item B', 'Item C']);

  usePageOnLoad((params) => {
    console.log('ListPage loaded, category:', params.category);
  });

  const openDetail = (id: string) => {
    Miniapp.navigateTo(
      `/detail?id=${id}&from=list`,
    );
  };

  const goHome = () => {
    Miniapp.reLaunch('/home');
  };

  return (
    <ScrollView contentContainerStyle={styles.container}>
      {items.map((item, i) => (
        <Button
          key={i}
          title={item}
          onPress={() => openDetail(String(i))}
        />
      ))}
      <Button title="العودة إلى الرئيسية" onPress={goHome} />
    </ScrollView>
  );
}

const styles = StyleSheet.create({
  container: { padding: 20 },
});
```

## ملاحظات

- يجب إعلان جميع الصفحات في مصفوفة `pages` داخل `app.json` قبل التنقل إليها
- معاملات الاستعلام تصل كسلاسل نصية ويجب تحويلها قبل الاستخدام
- قيمة `delta` في `navigateBack` لا يجب أن تتجاوز عمق المكدس الحالي
- `redirectTo` يُطلق حدث `onUnload` للصفحة المستبدلة
- `reLaunch` يُطلق `onUnload` لكل الصفحات التي تم مسحها
