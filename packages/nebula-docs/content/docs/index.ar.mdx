Nebula هي مجموعة miniapp للتطبيقات الفائقة. وهي توفّر runtime للمضيف، ونموذج تنفيذ للـ miniapp، ومسارات التثبيت وتحميل الـ bundle، ودعم التحميل المسبق، ومعمارية API يملكها المضيف لقدرات مثل `scanCode`.

صُمِّمت Nebula لثلاث فئات رئيسية:

- مهندسو المنصات الذين يدمجون Nebula داخل تطبيق مضيف
- مهندسو miniapp الذين يبنون تجارب المنتج فوق runtime الخاص بـ Nebula
- مهندسو الإطار الذين يوسّعون المكتبة الأساسية ونموذج قدرات المضيف

## ما الذي تحلّه Nebula

- إيقاع تطوير أسرع من ربط كل ميزة بإصدار جديد من تطبيق المضيف
- ملكية واضحة للقدرات الأصلية على جانب المضيف
- واجهات JavaScript مستقرة لفرق miniapp
- دعم أوضاع التشغيل في التطوير والإنتاج
- تحميل مسبق وتحكم في دورة الحياة لتسريع الإقلاع
- معمارية Host API قابلة للتوسعة للقدرات ذات الواجهة أو بدون واجهة
