يدعم Nebula Cloud النشر والتراجع عبر إدارة الإصدارات والتوزيع عبر القنوات.

## حالات الإصدار

```text
DRAFT -> PUBLISHED
```

| الحالة | المعنى |
|------|------|
| `DRAFT` | الحالة الأولية بعد الرفع |
| `PUBLISHED` | تم نشره للمستخدمين |

## القنوات

تحدد القنوات نطاق توزيع الإصدار. في الوقت الحالي، تذهب الإصدارات المرفوعة عبر CLI إلى قناة `stable` افتراضيًا.

| القناة | الوصف |
|------|------|
| `stable` | قناة الإنتاج لجميع المستخدمين |

## تدفق النشر

1. رفع إصدار (الحالة: `DRAFT`)
2. نشره للإنتاج (الحالة: `PUBLISHED`)
3. التراجع عند الحاجة
