---
title: 版本与渠道
description: 了解 Nebula 小程序的版本管理流程、发布渠道和版本状态流转。
---

Nebula Cloud 通过版本管理和渠道分发机制，支持小程序的发布和回滚。

## 版本状态

```text
DRAFT -> PUBLISHED
```

| 状态 | 说明 |
|------|------|
| `DRAFT` | 版本上传后的初始状态 |
| `PUBLISHED` | 已发布上线 |

## 渠道

渠道决定版本的分发范围。当前 CLI 上传的版本默认进入 `stable`。

| 渠道 | 说明 |
|------|------|
| `stable` | 生产渠道，面向所有用户 |

## 发布流程

1. 上传版本（状态：`DRAFT`）
2. 发布上线（状态：`PUBLISHED`）
3. 必要时回滚
