يدعم Nebula شاشة تحميل يملكها المضيف للتطبيقات المصغّرة. يتم عرض هذه الطبقة من خلال وقت تشغيل المضيف، وليس من التطبيق المصغّر نفسه.

## الاستخدامات المعتادة

- انتقالات بدء التشغيل
- عرض حالة التثبيت أو التحديث
- تجارب تحميل قابلة للعلامة البصرية
- تجنب الشاشة الفارغة قبل جاهزية الصفحة الأولى

## مكان الإعداد

يتم ضبطها عبر `miniappLoading` داخل `NebulaAPI.wrap()`:

- `component`
- `delayMs`
- `enterContentDelayMs`
- `resolveProps`
