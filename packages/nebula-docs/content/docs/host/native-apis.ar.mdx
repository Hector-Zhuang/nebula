---

تكشف Nebula طبقة الجسر الأصلي عبر `NebulaNativeModule`. وهذه الطبقة هي وسيلة النقل منخفضة المستوى بين وقت تشغيل JavaScript والتنفيذ الأصلي في المضيف.

## ما الذي ينتمي إلى الجسر الأصلي

- تثبيت التطبيقات المصغّرة وفتحها وتحميلها المسبق وإزالتها
- التنقل بين الصفحات وتحديث أنماطها
- بدائيات عرض Host modal
- نقل الرسائل بين المضيف والتطبيق المصغّر
- كشف القدرات في وقت التشغيل
- الإعدادات مثل `serverBaseURL`

## ما الذي لا ينبغي وضعه هنا

- قواعد الأعمال
- تدفقات المنتج
- منطق خاص بمستأجر معيّن
- دلالات API مخصصة يجب أن تعيش في Host API features
