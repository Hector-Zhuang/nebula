---
title: عزل الصندوق
description: تعرّف على آليات العزل في Nebula عبر نظام الملفات والتخزين وحالة وقت التشغيل.
---

يوفر Nebula لكل تطبيق مصغّر صندوقًا معزولًا. لا يستطيع تطبيق مصغّر الوصول مباشرة إلى ملفات أو تخزين أو حالة وقت التشغيل الخاصة بتطبيق آخر.

## طبقات العزل

- عزل نظام الملفات
- عزل التخزين
- عزل وقت التشغيل
- عزل bundle

## حدود التواصل

لا يمكن للتطبيقات المصغّرة التواصل مباشرة مع بعضها. وإذا لزم تبادل البيانات، فعلى المضيف أن يتولى الوساطة.
