توفر Nebula آلية مراسلة مدفوعة بالأحداث للتواصل بين المضيف والتطبيق المصغّر. يتم تمرير الرسائل على شكل كائنات JSON بدون بنية صارمة مفروضة مسبقًا.

## من المضيف إلى التطبيق المصغّر

استخدم `NebulaAPI.postMessageToMiniApp(appId, message)` لإرسال رسالة من المضيف إلى تطبيق مصغّر محدد.

## من التطبيق المصغّر إلى المضيف

استخدم `Miniapp.postMessageToHost(message)` لإرسال رسالة من التطبيق المصغّر إلى المضيف.

## متى تستخدم الرسائل

- إشعارات الأحداث
- مزامنة الحالة
- الإشارات الخفيفة عبر الحد الفاصل

أما إذا كنت تحتاج إلى قدرة منظّمة وقابلة للحوكمة وإعادة الاستخدام، فالأفضل استخدام Host API.
